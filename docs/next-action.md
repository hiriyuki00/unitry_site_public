## 3. YouTube アップロード手順（メモ）

1. Unitry アカウントでログイン → アップロード → アイコン → 動画を選択（目安 **50MB 未満**のファイル運用）
2. **タイトル・サムネ**を設定
3. 説明欄に記載する想定: 役者、撮影地、支援者、団体について、**HP のリンク**
4. 視聴者向け設定の目安
   - 子ども向け → **いいえ**
   - 成人向け制限 → **しない**
   - 字幕・終了画面 → 任意
   - カード → 関連リンク（HP 等）を追加可
5. 著作権・コミュニティ → オリジナル作品なら通常どおり進めてよい（不明点は YouTube 側ガイド参照）
6. **公開設定** → 団内合意・関係者確認後に「公開」または「限定公開」を選択
