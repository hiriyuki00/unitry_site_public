### 1.2 団体の背景と社会的ミッション

Unitry は千葉県我孫子市を拠点とする映像制作の任意団体である。

**プロジェクトを通して達成したい目的：**

- 我孫子市内にある二つの大学を盛り上げること

**映像作品として伝えたいこと：**

- 子どもにとって大学生と交流することがどれほど素晴らしいか
- 交流する中での、大学生と子どもそれぞれの変容

**社会的背景：**

- 責任者は、子どもの生きづらさの解消に取り組む人物である
- 「多様な大人と出会い、会話・対話すること」が子どもの生きづらさ解消の一つの可能性であると考えている
- 映画プロジェクトを通して、さまざまな子どもが大人と会話・対話する環境を作ることを目指す
- 制作を通じて生まれたつながりが、制作終了後も子どもに影響を与え続けることを期待している

**活動の目指すところ：**

- 我孫子市と市内の大学を盛り上げるため、広報力強化に寄与する
- 大学生の地域への貢献を伝える
- 地域の子どもからお年寄りまで幅広い層の関わりを促し、地域社会の絆を深める

### 1.3 HPの目的

映像制作を行う任意団体 Unitry の**理念や活動を理解してもらう**ための公式ウェブサイトを構築する。

具体的には以下を目的とする：

1. **団体の理念・活動を理解してもらう**（最優先）
  - 「交流」を軸とした社会的ミッションへの共感を生む
2. **活動への参加・協力を促す**
  - ボランティア希望者・プロジェクト参加者の問い合わせ
3. **対外的な信頼性を確保する**
  - 協賛・協力を検討する企業・個人への情報提供
4. **制作実績を発信する**
  - 映像作品を通じて団体の活動成果を可視化する

### 1.4 開発・運用方針

- コード生成・開発：**Cursor** を使用
- フレームワーク：**Next.js（React）**
- ホスティング：**Vercel**（`xxx.vercel.app` サブドメインを使用）
- 更新頻度：**月1回程度**の定期更新（ニュース・お知らせ、作品追加）

## 3. サイト構成（ページ設計）

### 3.1 サイトマップ

```
トップページ（/）
├── 団体について（/about）
│   ├── 理念・ミッション
│   └── メンバー紹介
├── 作品（/works）
│   ├── 作品一覧（映像サムネイル＋説明）
│   └── 作品詳細（/works/[id]）
├── ニュース・お知らせ（/news）
│   ├── 一覧
│   └── 詳細（/news/[slug]）
├── ご支援（/support）
│   └── CAMPFIRE クラウドファンディング埋め込み
└── お問い合わせ（/contact）
```

### 3.2 ページ詳細

#### トップページ（/）

訪問者が最初に目にするページ。団体の世界観を伝え、理念への共感を生むことを最優先とする。

**セクション構成**:

1. **ヒーロー**
  - 背景に映像を流す（映像制作団体としてのブランディング）
  - キャッチコピー + 団体名を表示
  - 「交流」「子どもと大学生の変容」を感じさせるビジュアル
2. **Unitryとは**
  - 団体の理念・ミッションを簡潔に紹介
  - 「なぜ映像制作なのか」「何を目指しているのか」を伝える
  - About ページへの導線
3. **Works ハイライト**
  - 直近の制作実績をピックアップ表示
  - Works ページへの導線
4. **News 最新記事**
  - 直近のお知らせ 2〜3件を表示
  - News ページへの導線
5. **参加しませんか（CTA セクション）**
  - ボランティア・プロジェクト参加に興味がある方へのメッセージ
  - お問い合わせページへの誘導
6. **フッター**
  - Instagram リンク
  - ナビゲーション
  - コピーライト

#### About ページ（/about）

団体の理念と活動の「なぜ」を深く伝えるページ。

- **理念 / ミッション**
  - 「交流」を中心とした団体の理念
  - 子どもの生きづらさ解消への想い
  - 大学生と子どもの交流がもたらす価値
  - 映像制作という手段を選んだ理由
- **活動内容の紹介**
  - 映像制作プロジェクトの概要
  - 地域社会との関わり
- **メンバー紹介**
  - 名前・写真・役割・紹介文

#### Works ページ（/works）

- 映像作品の一覧（サムネイル + タイトル + 概要）
- 各作品に詳細ページあり（/works/[id]）

#### Works 詳細ページ（/works/[id]）

- **YouTube 埋め込み**で動画を直接再生可能
- 各作品に以下の情報を付与:
  - 作品タイトル
  - 説明文・制作背景
  - YouTube 動画 ID
  - 制作年（任意）
  - カテゴリ / タグ（任意）

#### News ページ（/news）

- お知らせ記事の一覧
- **Markdown ファイルで管理**
- 各記事の個別ページあり（/news/[slug]）
- 記事に含む情報:
  - タイトル
  - 公開日
  - 本文（Markdown）
  - カテゴリ（任意）

#### お問い合わせページ（/contact）

- **Google フォームの埋め込み**
- 以下の用途で使用:
  - ボランティア・プロジェクト参加の問い合わせ
  - 協賛・協力の問い合わせ
  - その他の一般的な問い合わせ

### 3.3 Next.js ルーティング方針

- App Router を使用（Next.js 13以降）
- 作品詳細は動的ルート `/works/[id]` で実装
- ニュース詳細は動的ルート `/news/[slug]` で実装
- SSG（Static Site Generation）を基本とし、ビルド時にページを生成する

## 4. 機能要件

### 4.1 作品・活動発信機能（コア機能）

- 作品一覧ページに映像のサムネイル・タイトル・概要を表示する
- 映像は **YouTube に手動でアップロードし、埋め込みコードで表示** する
  - 映像ファイル自体は Vercel に置かない（サーバー負荷・容量の観点）
- 作品詳細ページで映像プレイヤー・説明文・制作背景を表示する
- 月1回の更新で作品・ニュースを追加できる構成にする

### 4.2 ニュース・お知らせ機能

- ニュース一覧・詳細ページを実装する
- 更新方法：**Markdown ファイルを編集 → Vercel に再デプロイ** して更新
  - CMS不要・コストゼロで運用可能な構成とする
- 投稿にはタイトル・日付・本文（Markdown）を含む

### 4.3 お問い合わせ

- **Google フォーム**を埋め込みで設置
- ボランティア募集・協賛問い合わせもこのページで対応

## 5. 非機能要件

### 5.1 デザイン・UI


| 項目       | 要件                                                          |
| -------- | ----------------------------------------------------------- |
| デザイントーン  | **モダン・ミニマル**（シンプルで洗練された印象）                                  |
| ブランドカラー  | プライマリ: **赤**（アクセント）、セカンダリ: **黒**（テキスト・背景）、ベース: **白**（背景・余白） |
| ブランド素材   | ロゴは確定済み（後日共有予定）。仮のタイポグラフィロゴで進行                              |
| アニメーション  | ほどよい演出（フェードイン、スクロール連動の軽いアニメーション）                            |
| レスポンシブ対応 | **PC・スマートフォン・タブレット対応必須**（モバイルファースト）                         |
| アクセシビリティ | セマンティック HTML、適切な alt テキスト、文字サイズ・コントラスト比の確保                  |


### 5.2 パフォーマンス

- Next.js の SSG により高速な初期表示を実現する
- 映像コンテンツは YouTube を利用し、Vercel への負荷を回避する
- 画像は `next/image` コンポーネントで最適化する
- 目標：**Google PageSpeed Insights スコア 90 以上**

### 5.3 セキュリティ

- Vercel により自動で HTTPS 化される
- 環境変数（APIキー等）は `.env.local` で管理し、コードに直接記述しない

### 5.4 SEO

- Metadata API でメタタグ（title / description）を各ページに設定する
- OGP（Open Graph Protocol）設定（SNSシェア時のカード表示対応）
- `sitemap.xml` を自動生成する

## 11. 更新フロー（運用手順）

月1回の更新は以下のフローで行う：

```
1. 映像を YouTube にアップロード → URLを控える
2. src/data/works.ts に作品データを追加する
3. content/news/ にニュース記事の Markdown ファイルを追加・編集する
4. Vercel にデプロイ（git push または Vercel CLI）
5. 公開確認
```

## 13. 制約・前提条件

- 任意団体のため、制作・運用予算は限定的（Vercel 無料プランの範囲内で運用）
- CMS は使用せず、ファイルベースでコンテンツを管理する（コスト・複雑さを回避）
- 映像ファイルは Vercel に置かず、YouTube を経由して表示する
- ドメインは `.vercel.app` サブドメインを使用（独自ドメイン取得は将来対応）
- 大学名はHP上に掲載しない
- 今後、映画以外のプロジェクトを行う可能性があるため、拡張性を考慮した設計とする

## 14. サイトのトーン・メッセージング方針

HPを通じて伝えるべきメッセージの優先順位：

1. **交流が生む変容** — 大学生と子どもの交流を通じた互いの成長と変化
2. **子どもの可能性を広げる** — 多様な大人との出会いが子どもの生きづらさを和らげる
3. **地域社会の絆** — 子どもからお年寄りまで幅広い層の関わりを促す
4. **映像の力** — 映像制作を通じて人をつなぎ、まちを盛り上げる

※ サイト全体を通じて、「温かさ」と「真剣さ」が共存するトーンを心がける。
